# Latin Grammar

Turn the learner's actual sentence or grammar question into an explanation they can apply. Match the requested depth and explanation language; a small question does not require a full grammar report.

## Analyse before correcting

Consult [analysis conventions](references/analysis-guide.md) for the teaching pattern and examples. Preserve the original text, including macrons where supplied. Identify the context and any genuine ambiguity before declaring a form wrong.

For a sentence, give a natural translation followed by the forms and relationships necessary to justify it. Describe case, number, gender, person, tense or mood only where they resolve the question. If several parses are possible, distinguish them and request context only when it changes the answer.

For a correction, present the original, a minimal correction and the reason. Label optional stylistic improvements separately. Latin word order is flexible; do not correct a grammatical sentence solely to impose a preferred order. Missing macrons are normally a notation difference, not a grammatical error.

## Practise the same point

If the learner wants practice, offer one small exercise using the same grammatical feature. Keep its answer hidden until they try or request it. Evaluate meaning and valid alternatives, not an exact string. Explain one misconception before introducing another topic.

Use constructed examples and label them as such. Do not invent classical quotations, editions, citations or claims that an example appears in a named author. Explain uncertainty openly; for a difficult reading, offer a provisional analysis instead of a fabricated definitive answer.

## Runtime boundary

The learner's AI tool performs the analysis using this package and its own model. No Latinviva account, backend, model proxy, payment or key is required. Do not add network calls, telemetry, or a company-funded fallback. Do not claim access to the learner's App history. Write local notes only at the learner's request; do not insert brand advertising into an explanation.
