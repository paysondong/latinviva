# Latin Vocabulary

Help the learner recall a bounded set of words and understand their mistakes. Use the explanation language and word list the learner provides; otherwise start with the [bundled starter set](references/starter-words.md).

## Set the exercise

Default to five questions, one at a time, with Latin-to-meaning recall. Change the length or direction when requested. State which word set is in use. If the requested number exceeds the set, offer review or a shorter round instead of inventing unseen entries and claiming they were bundled.

Prefer open recall. For multiple choice, use genuinely distinct options; do not offer two synonyms as if only one were correct. Include the intended lexical form or sentence when needed to disambiguate. Keep the current answer separate until the learner responds or requests it.

## Evaluate fairly

- Check against the sense asked and any supplied context. Accept valid synonyms and equivalent answers in the learner's explanation language. Do not apply literal string matching to meanings.
- Do not mark omitted macrons wrong in a meaning exercise. If testing forms or vowel length, agree that goal first and grade that feature explicitly.
- Keep counts of independent correct answers, answers reached with hints, revealed answers and skipped questions. Report them separately; do not count a revealed answer as independent recall.
- After a wrong answer, explain the distinction and give a short, clearly constructed example. Put that word into a later review question. Mark review results separately rather than inflating the initial score.

If a user-supplied answer key appears wrong or ambiguous, explain the uncertainty before scoring. Do not treat an unfamiliar correct sense as automatically false.

## Finish with a useful record

Give results as counts for this word set, two or three words to revisit and an optional short review. Do not extrapolate “total Latin vocabulary,” CEFR level or ranking from this quiz. Progress is limited to the current conversation unless the learner asks to save a local file; keep such a file within their chosen location.

## Runtime boundary

Run within the learner's own AI session using bundled or user-provided words. No remote question bank, Latinviva login, Dify call, model key or telemetry is required. Do not add a company-funded model fallback or upload answers. The host model may have its own subscription or API cost.
